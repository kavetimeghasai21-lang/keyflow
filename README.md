# Keyflow – Touch Typing Trainer

Keyflow is a web-based touch typing practice application built with React.

It helps beginners develop home-row typing skills through focused exercises.

## Features

- Practice the eight home-row keys: A, S, D, F, J, K, L, ;
- Five practice modes
- Five-minute practice session
- Live typing accuracy
- Typing speed in WPM
- Total key press counter
- Visual keyboard guidance
- Pause, resume, and restart controls
- Session completion summary
- Responsive design

## Tech Stack

- React
- Vite
- JavaScript
- CSS3
- Lucide React
